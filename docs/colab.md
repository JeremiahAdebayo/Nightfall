# Colab walkthrough (no local GPU required)

Local GPU is the primary setup path. If you don't have a GPU, Google
Colab's free T4 runtime is the supported alternative -- training is the
only GPU-hungry step; eval, calibration, and serving all run fine on CPU.

Run each block below as its own Colab cell, in order. Checkpoints, data,
and ONNX artifacts live on Google Drive so a runtime disconnect never
loses progress.

```python
    --onnx-path {DRIVE_ROOT}/onnx/feature_extractor_int8.onnx
```

The default run is the mismatched-bank baseline (INT8 test features scored
against banks built from fp32 train features) -- pessimistic, since the
feature-space mismatch itself, not quantization, caused most of the
collapse seen in the notebook. The real experiment is the consistent
pipeline, which refits each bank with the same INT8 extractor used for
scoring:

```python
!python scripts/run_eval_int8.py \
    --data-root {MVTEC_DIR} \
    --checkpoint-dir {DRIVE_ROOT}/checkpoints \
    --onnx-path {DRIVE_ROOT}/onnx/feature_extractor_int8.onnx \
    --refit-bank --save-refit
```

`--save-refit` writes each refit bank to
`<checkpoint-dir>/<category>_memory_bank_int8.pt`; later `--refit-bank`
runs reload it automatically instead of re-extracting the training set.

## 7. Expose publicly (for the ESP32 client)

Plain HTTP on purpose -- ESP32's mbedTLS fails the TLS handshake against
most HTTPS tunnels (see README "Edge integration"):

```python
!npm install -g localtunnel
```

```python
import subprocess, time, re
proc = subprocess.Popen(["lt", "--port", "8000"],
                        stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True)
url = None
start = time.time()
while time.time() - start < 20:
    line = proc.stdout.readline()
    m = re.search(r"https?://[a-zA-Z0-9\-]+\.loca\.lt", line)
    if m:
        url = m.group(0).replace("https://", "http://")
        break
print(f"Use in esp32_client.ino: {url}/detect")
```
